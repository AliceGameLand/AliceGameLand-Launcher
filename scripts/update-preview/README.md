# 업데이트 화면 체험

저장소 루트의 `업데이트 체험.cmd`를 실행한다. 로컬 node_modules와 형제 AliceGameLand-Distribution 저장소를 사용한다.

1. 약 3초 뒤 상단에 나타나는 업데이트 버튼을 누른다.
2. 설정의 업데이트 탭에서 테스트 릴리스 내용과 설치하기 버튼을 확인한다.
3. 설치하기를 누르면 체험 완료 안내가 나타난다.
4. 업데이트 확인을 누르면 같은 흐름을 다시 체험할 수 있다.

이 창에는 `업데이트 체험` 표시가 있으며, 버전·접속 인원·계정은 테스트 데이터다. 실제 다운로드·재설치·게임 실행을 하지 않는다. 실제 업데이트 이벤트를 받는 기존 렌더러를 사용하되, 메인 프로세스는 electron-updater 대신 테스트 알림만 보낸다. 설정은 임시 폴더의 별도 프로필에 저장한다.

자동 확인: `node_modules/electron/dist/electron.exe scripts/update-preview/main.cjs --verify`

검증 모드는 창을 표시하지 않고 알림 → 업데이트 탭 → 설치 → 완료 및 창 버튼의 hover 크기를 확인한다. 캡처는 `.impeccable/review/update-preview`에 저장한다. 실제 업데이트 배포·다운로드·재설치 검증과는 구분한다.
