# 앨리스의 게임랜드 1.0.27

- 실행 중인 게임이 있어도 버튼 이름을 **플레이**로 통일했습니다.
- 정상 검사한 파일의 크기·시간·파일 식별자와 기대 해시가 같으면 검증 결과를 재사용해 반복 파일 확인의 읽기 작업을 줄였습니다. 변경·누락 파일은 다시 확인하며, 캐시는 최대 24시간만 사용합니다.
- 다운로드 후 검사는 기존 방식으로 유지합니다.
- 게임 준비 진행바는 이전 디자인과 애니메이션을 유지합니다.
- 업데이트와 설치파일 재실행 시 기존 설치 경로와 설치 범위를 인식하고 바로가기를 보존하는 업데이트 모드로 진행하도록 수정했습니다.
- Windows 앱 식별자를 설치 바로가기와 동일하게 고정했습니다.
- 전체 화면 설정이 게임 실행 인자와 옵션에 반영되도록 수정했습니다. 다른 게임 옵션은 유지합니다.

검증: lint·회귀 테스트 36개 통과, 격리 UI 흐름·패키지 검증. 실제 게임 전체 화면과 Windows 작업 표시줄 고정 유지의 실기 검증은 포함하지 않았습니다.
