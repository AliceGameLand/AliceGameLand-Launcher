# 앨리스의 게임랜드 1.0.44 · Tauri Windows

- Windows x64용 Tauri 런처를 정식으로 제공합니다.
- 기존 Electron의 게임 경로와 설정을 이어 쓰고, 선택된 Microsoft 계정을 Windows 자격 증명 보관함으로 가져옵니다.
- WebView2가 없으면 설치 중 Microsoft 서버에서 자동으로 내려받습니다.
- 기존 Electron에서 업데이트를 선택하면 Tauri 설치 화면이 열립니다. Tauri 설치를 확인한 뒤 제어판에서 기존 Electron 런처를 제거할 수 있습니다.
- 게임 프로세스가 시작된 뒤 실행 중 표시를 7초 동안 유지합니다.
