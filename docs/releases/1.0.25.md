# 앨리스의 게임랜드 1.0.25

- 홈의 서버 목록과 실행 영역, 설정 화면의 글자와 입력창 정렬을 다듬었습니다.
- 로그인 화면의 여백을 줄이고 환영 안내를 추가했습니다.
- 하단 도구의 위아래 여백을 맞추고, 런처 버전을 문제 신고 오른쪽에 배치했습니다.
- 클릭음을 짧고 부드러운 탭 소리로 변경했습니다.
- 게임 준비가 끝나면 **추가 실행**으로 여러 게임 창을 실행할 수 있습니다. 준비 중 중복 실행은 계속 차단합니다.
- 게임 준비 오류에 다시 시도, 문제 신고, 민감 정보를 가린 오류 정보 복사를 추가했습니다.
- 상태를 조회하지 못한 서버의 긴 설명을 제거하고, 설치·실행 준비는 실제 백분율 대신 불확정 진행바로 표시합니다.
- 잘못된 해상도가 서버 변경 과정에서 저장되는 문제와 로그인 실패 후 계정 없는 홈으로 이동하는 문제를 수정했습니다.

업데이트 알림에서 다운로드와 설치를 직접 선택해 주세요.

검증: lint·회귀 테스트 26개 통과, 1280×720·1024×600·640×480 및 150% 배율 확인. 복수 실행 흐름은 격리된 모의 프로세스로 검증했습니다.
