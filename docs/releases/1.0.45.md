# 앨리스의 게임랜드 1.0.45 · Tauri

- 기존 Windows Electron 런처에서 업데이트를 선택하면 새 Tauri 설치 화면이 열립니다. 기존 게임 폴더와 선택한 Microsoft 계정을 이어서 사용합니다.
- WebView2가 없으면 설치 과정에서 자동으로 내려받고, 게임 프로세스가 시작되면 실행 중 표시를 7초 동안 유지합니다.
- Windows와 Apple Silicon 맥에서 Java 25 실행 파일을 선택하고 서버별 JVM 인수를 저장할 수 있습니다.
- 설정의 저장 버튼을 고정하고, 맥에서 제목 표시줄을 드래그할 수 있도록 했습니다. 켜진 토글의 손잡이 위치도 조정했습니다.
- Apple Silicon용 DMG는 Apple 공증이 적용되지 않은 빌드입니다.
